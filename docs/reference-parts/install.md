## Install

Requires Node.js 22 or newer. End users do not need Bun or TypeScript.

```sh
npm install -g boldvideo
boldvideo --version
boldvideo --help
```

For a one-off invocation without a global install, use `npx boldvideo --help`.
This page covers the commands registered in the version named in its generated
comment. The command reference below is authoritative for that version; planned
commands are not silently presented as available.
